NOM DU PROJET : MOMOJOB - Recherche d'Alternance Premium

DESCRIPTION : MOMOJOB est un outil moderne qui regroupe les offres d'alternance en temps réel. L'objectif est de proposer une interface rapide, propre et efficace pour trouver son futur contrat sans perdre de temps.

PRINCIPALES FONCTIONNALITES :

Recherche instantanée par métier et par ville.

Design moderne avec mode sombre et mode clair.

Barre de progression lors de la recherche des offres.

Bouton pour copier les liens des annonces en un clic.

Export des résultats au format CSV (pour Excel ou Notion).

Interface totalement adaptable sur mobile et tablette.

COMMENT L'UTILISER :

Télécharger les fichiers du projet.

Ouvrir le fichier index.html dans n'importe quel navigateur (Chrome, Firefox, Safari).

Taper un métier et une ville, puis cliquer sur Explorer.

TECHNO UTILISEES :

HTML5

CSS3 (Design avec effets de transparence et dégradés)

JavaScript (Vanille)

API Adzuna pour les offres en temps réel

FontAwesome pour les icônes
